#  Power BI E-Commerce Sales Dashboard

## Project Overview

This project presents an interactive **Power BI dashboard** analyzing e-commerce sales performance.
The dashboard helps track business performance using key metrics such as **Sales, Profit, Quantity, and Profit Margin**.

## Key Features

* YTD Sales, Profit, Quantity, and Profit Margin analysis
* Year-over-Year (YoY) comparison
* Sales analysis by **Category**
* **Top 5 and Bottom 5 Products**
* Regional sales analysis
* Shipping type analysis
* Customer segment filtering

## Tools Used

* Power BI
* Data Modeling
* DAX
* Data Visualization
